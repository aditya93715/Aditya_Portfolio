### Key Projects & Contributions

**RHT Monitor Dashboard** is a real-time environmental monitoring dashboard that I built and deployed to track temperature and humidity readings from connected devices, using the MERN stack on a Linux (Ubuntu) server. I developed the Node.js and Express.js backend to ingest sensor data and expose RESTful APIs for both live and historical readings, and I designed MongoDB collections optimized for high-volume, time-based data so that queries remain fast as the dataset grows. On the frontend, I built a React interface that presents live values, historical trend charts, and threshold-based visual alerts, and I configured and maintained the deployment on the company's production server to ensure round-the-clock uptime.

**Freetrack** is a real-time tracking system with an integrated multi-level admin structure (Super Admin, Admin, Sub-Admin) that I built and deployed using the full MERN stack. I implemented JWT-based authentication and role-based route protection on the Node.js and Express.js backend, and I designed MongoDB schemas to store tracking records, complete status history, users, roles, and permissions. I also developed REST APIs for creating, updating, and retrieving tracking entries across every access level, and built a responsive React frontend that gives end users a clear status timeline while providing each admin role its own dedicated dashboard.

**Srishti Wireless Solution's official website** is the company's primary online presence for showcasing services, ongoing projects, and contact information, which I built using the MERN stack. I developed responsive React frontend sections covering the company overview, services, and inquiry forms, and built Node.js and Express.js APIs to handle contact form submissions and deliver structured content. I used MongoDB to store editable service and inquiry content so the site can be updated without any code changes, and I deployed and maintained the site on the company's production server in line with its branding.
